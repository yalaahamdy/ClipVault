## 📖 نبذة عن المشروع (About ClipVault)

**ClipVault** هو تطبيق سطح مكتب متكامل، فائق السرعة، وخفيف للغاية مخصص لنظامي Windows 10 و 11. يجمع بين:
1. **مدير حافظة ذكي متعدد الوسائط**: يسجل النصوص، الأكواد، الروابط، الصور، والملفات بدون أي استهلاك ملحوظ للعتاد.
2. **جناح الكتابة الذكي والتدقيق الشامل (Smart Writing Suite)**: يحل مشكلة نسيان تبديل لغة لوحة المفاتيح في أي تطبيق فوراً، مع مدقق إملائي احترافي، كتابة صوتية، وتوقع للكلمات.
3. **محرك OneOCR Professional المدمج محلياً**: يستخرج النصوص العربية والإنجليزية من الصور ولقطات الشاشة في أجزاء من الثانية.
4. **خزينة كلمات مرور مشفرة بتشفير عسكري AES-256-GCM**: تحمي بيانات تسجيل الدخول وبطاقات الدفع والملاحظات السرية محلياً 100%.

تم بناء التطبيق باستخدام **Tauri v2** و **Rust** مع واجهة تفاعلية حديثة بـ **React 18 + TypeScript** لتقديم سرعة استجابة مذهلة واستهلاك ذاكرة متواضع جداً (~15 إلى 35 ميجابايت).

> [!NOTE]
> **محلي 100% (Zero-Knowledge & Local-First):** لا يتصل التطبيق بأي خوادم خارجية ولا يرسل أي بيانات عبر الإنترنت. جميع نصوصك وصورك وكلمات مرورك مخزنة ومشفرة محلياً على جهازك فقط.

## ✍️ جناح الكتابة الذكي والتدقيق اللغوي (Smart Writing Suite)

يحل ClipVault أشهر مشاكل الكتابة وأكثرها إحباطاً لمستخدمي نظام Windows من خلال جناح ذكي متكامل:

### 1. 🔄 عكس لغة لوحة المفاتيح اللحظي (Keyboard Layout Inverter)
- **حل مشكلة نسيان تبديل اللغة (Alt+Shift)**: عندما تكتب نصاً طويلاً وتتفاجأ أنك كنت تكتب بحروف لغة أخرى مثل:
  - `hghsjo]hl` ➔ يتحول بضغطة زر إلى `الاستخدام`.
  - `صصصزلخخلمثزؤخة` ➔ يتحول تلقائياً إلى `www.google.com`.
  - `ClipVault` ➔ يتحول إلى `زمهحثفعمف`.
- **زر اللصق والعكس الفوري بضغطة واحدة (⚡ Quick Paste & Invert)**:
  - قراءة محتوى الحافظة وعكس لغته ونسخ النتيجة تلقائياً دون الحاجة لكتابة أي حرف!
- **تصحيح النص المحدد في أي تطبيق نشط (System-Wide Active Selection Fixer)**:
  - لا داعي لنسخ النص وفتح التطبيق! فقط ظلل النص في أي برنامج (Word, Chrome, Notepad, Discord, VS Code...) واضغط على <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> وسيقوم ClipVault بتصحيح لغته واستبداله في مكانه فوراً!

### 2. 🪄 المدقق الإملائي واللغوي الاحترافي الشامل (Pro Morphological Spell Checker)
- **محرك لغوي صرفي متقدم**: تفكيك السوابق واللواحق الصرفية (حروف العطف و، ف، حروف الجر ب، ل، ك، وأل التعريف) مع فحص جذع الكلمة وإعادة تركيبه بدقة تامة.
- **تصحيح متقدم للهمزات**:
  - همزات القطع الواجبة (أفعل التفضيل، جموع التكسير أفعال وأفعلة، مصادر الرباعي إفعال، وأسماء الأعلام).
  - همزات الوصل التلقائية في الخماسي والسداسي (استخدام، استدعاء، انتظار، اختيار، اكتشاف).
- **التاء المربوطة والهاء**:
  - قواعد اشتقاقية دقيقة لأسماء النسبة (تقنية، شخصية، ذكية، أهمية، عملية...).
  - أوزان الصفات المؤنثة واسم الفاعل والمفعول (جديدة، جميلة، شاملة، كاملة، معلومة).
  - استثناء صارم للكلمات ذات الهاء الأصلية (مياه، فواكه، توجيه، تنبيه، وجيه، فقيه).
- **الألف المقصورة والياء**: تصحيح الكلمات المقصورة والزوائد (إلى، على، حتى، بلى، مستشفى، منتدى، أخرى، أقصى، أعلى).
- **التنوين مقابل النون الساكنة**: معالجة معجمية ممتدة (شكراً وليس شكرن، عفواً وليس عفون، أهلاً وليس اهلن، دائماً وليس دايمن، جداً وليس جدن).
- **تصحيح الأخطاء الشائعة الملتصقة**: (إن شاء الله، بإذن الله، هذا وليس هاذا، لكن وليس لاكن، شيء وليس شئ، مسؤول، مظهر، حظاً).
- **شرائح تصفية الأخطاء التفاعلية (Interactive Filter Chips)**: تصنيف الأخطاء حسب النوع (الهمزات، التاء المربوطة، التنوين، الترقيم، أخطاء شائعة) مع عداد لكل صنف.
- **مؤشر دقة وسلامة النص (Text Accuracy Meter)** مع زر السحر لتصحيح كافة الأخطاء دفعة واحدة بنقرة واحدة (<kbd>Ctrl</kbd>+<kbd>Enter</kbd>).

### 3. 🎙️ استوديو الإملاء الصوتي والنطق (Voice Studio & TTS)
- **تفريغ صوتي فوري عالي الدقة**: تحدث عبر الميكروفون باللغة العربية (فصحى أو لهجات) أو الإنجليزية ليتم تحويل صوتك إلى نص مكتوب بسرعة ودقة فائقة.
- **محاكي نبضات وأمواج صوتية حية (Audio Visualizer)** مع عداد زمني للتسجيل بالثواني والدقائق.
- **الاستماع ونطق النص (Text-To-Speech)**: زر للاستماع إلى النطق السليم للنصوص المفرغة أو المصححة للتأكد من سلامتها.
- **ضخ النص المباشر (Inject into Active App)**: زر لنقل ولصق النص المفرغ صوتياً إلى البرنامج المفتوح لديك فوراً بنقرة أو عبر اختصار <kbd>Shift</kbd>+<kbd>Enter</kbd>.

### 4. 📱 شريط توقع واقتراح الكلمات (Mobile-Style Word Predictions)
- شريط اقتراحات تفاعلي في أعلى المحرر يقترح الكلمات التالية ويكمل الكلمة الحالية بنمط لوحات مفاتيح الهواتف الذكية (Gboard / SwiftKey).

## 🔍 محرك استخراج النصوص (OneOCR Professional Engine)

تم دمج محرك **OneOCR Professional** المتقدم المبني على تقنيات الذكاء الاصطناعي لـ Microsoft OneOCR للعمل محلياً بصمت وسرعة قياسية:

- **استخراج فوري فائق الدقة**: استخراج النصوص والأسطر ومربعات الإحاطة في أقل من نصف ثانية دون اتصال بالإنترنت.
- **تكامل تام في بطاقات الحافظة**:
  - شريط مقتطف أنيق أسفل كل صورة يعرض النص المستخرج منها.
  - شارة مميزة ثلاثية الأبعاد `[ 🔍 OCR ]` لتمييز الصور ذات النصوص.
  - زر مسح سريع ونسخ مباشر للنص المستخرج بنقرة واحدة.
- **قائمة الزر الأيمن (Context Menu)**: خيارات مباشرة لاستخراج النصوص أو نسخها فوراً.
- **شاشة المعاينة الفائقة**:
  - تبويبة مزدوجة: `[ 🖼️ الصورة ]` و `[ 📝 النص المستخرج (OCR) ]`.
  - **مؤثر شعاع ليزر متوهج ثلاثي الأبعاد (Laser Scanner Animation)** أثناء معالجة الصورة.
  - عرض النصوص في محرر أنيق ذي أسطر مرقمة مع إحصائيات دقيقة: عدد الأسطر، عدد الكلمات، وعدد الأحرف.
  - زر نسخ كامل وزر إعادة الفحص (Re-scan).

## 🔐 خزينة كلمات المرور (Professional Password Vault)

يوفر ClipVault خزينة متكاملة لحفظ وإدارة كلمات المرور بأعلى معايير الأمان العالمية:

1. **تشفير عسكري AES-256-GCM**:
   - اشتقاق المفتاح الرئيسي باستخدام 10,000 جولة من خوارزمية SHA-256 مع Salt عشوائي فريد لكل مستخدم.
   - حماية كاملة ضد الاختراق والتطفل المحلي.
2. **قفل برمز PIN ذكي**:
   - إعداد قفل رئيسي برمز PIN مع إمكانية القفل اليدوي أو التلقائي بعد مدة خمول محددة.
3. **استيراد وتصدير Chrome Passwords CSV**:
   - استيراد وتصدير فوري متوافق 100% مع متصفحات: Google Chrome, Microsoft Edge, Brave, و Opera.
4. **فحص وتدقيق الأمان (Security Audit)**:
   - فحص صحة الحسابات وتنبيهك بكلمات المرور الضعيفة والمكررة بنقرة واحدة.
5. **مولد كلمات مرور احترافي**:
   - توليد كلمات مرور معقدة مع التحكم بالطول، الأحرف الكبيرة/الصغيرة، الأرقام، والرموز الخاصة.
6. **مسح أمني تلقائي للحافظة (Auto-Clear)**:
   - مسح تلقائي لأي كلمة مرور يتم نسخها بعد 30 ثانية لضمان عدم تسريبها.

## 🖥️ معاينة المحتوى الاحترافية (Universal Pro Preview)

- **أداة التنسيق الذاتي (HTML Beautifier)**: إعادة تنظيم وترتيب الشفرات المتراصة بهندسة وتنسيق تلقائي.

### 2. 📝 عارض Markdown العصري (Notion & GitHub Inspired)
- دعم كامل لتنبيهات GitHub الملونة:
  - `> [!NOTE]` — ملاحظة هامة ℹ️
  - `> [!TIP]` — نصيحة مفيدة 💡
  - `> [!IMPORTANT]` — تنبيه فائق الأهمية 📌
  - `> [!WARNING]` — تحذير وتنبيه ⚠️
  - `> [!CAUTION]` — خطر 🛑
- جداول ثلاثية الأبعاد بأسلوب Notion وقوائم مهام تفاعلية `- [ ]` و `- [x]`.

### 3. 💻 تلوين الأكواد البرمجية (Tokyo Night)
- تلوين دقيق لكافة اللغات البرمجية مع زر تبديل **التفاف الأسطر الطويلة (Word Wrap)** وشريط ترقيم أسطر أنيق.

### 4. 🖼️ عارض الصور المتقدم
- تكبير وتصغير سلس (Zoom)، تدوير بمقدار 90 درجة، سحب وإزاحة (Pan)، وتبديل خلفية الشفافية (Grid / Dark / Light).

| <kbd>Ctrl</kbd> + <kbd>5</kbd> | الانتقال إلى شاشة الإعدادات |
| <kbd>Enter</kbd> (في وضع القص) | نسخ فوري للقطة الشاشة واستخراج النصوص بالحافظة |
| <kbd>A</kbd> (في وضع القص) | فتح محرر الرسم والتعليق الهندسي على لقطة الشاشة (Annotate) |
| <kbd>Alt</kbd> + <kbd>1…3</kbd> | التبديل بين أدوات الكتابة (1: عكس اللغة، 2: المدقق، 3: الصوت) |
| <kbd>Alt</kbd> + <kbd>S</kbd> | تبديل اتجاه لغة التحويل يدوياً (عربي ↔ إنجليزي) |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | نسخ النتيجة المعكوسة / تطبيق تصحيح الأخطاء بالكامل |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | ضخ ولصق النص الناتج في التطبيق النشط فوراً |
| <kbd>Ctrl</kbd> + <kbd>M</kbd> | تشغيل / إيقاف الميكروفون والإملاء الصوتي |
| <kbd>↑</kbd> <kbd>↓</kbd> / <kbd>Shift</kbd> + <kbd>↑↓</kbd> | التنقل بالأسهم بين العناصر / قفز سريع |
| <kbd>Enter</kbd> | نسخ العنصر المحدد ولصقه تلقائياً وإخفاء النافذة |
| <kbd>Space</kbd> | فتح نافذة المعاينة الشاملة للعنصر المحدد |
| <kbd>Delete</kbd> | حذف العنصر من السجل |
| <kbd>Ctrl</kbd> + <kbd>T</kbd> | تبديل مظهر الواجهة (داكن / فاتح) |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> | فتح لوحة إدارة الوسوم والمجموعات |
| <kbd>Esc</kbd> | إغلاق النوافذ المنبثقة أو إلغاء لقطة الشاشة أو إخفاء الحافظة |

## 🛠️ البناء من المصدر (Building from Source)

```bash
# 1. استنساخ المستودع
git clone https://github.com/yalaahamdy/ClipVault.git
cd ClipVault

# 2. تثبيت مكتبات الواجهة
npm install

# 3. تشغيل وضع التطوير الحي
npm run tauri dev

# 4. تجميع مثبت الإنتاج النهائي (NSIS)
npm run tauri build
```

ينتج ملف التثبيت المجمع في المسار:
`src-tauri/target/release/bundle/nsis/ClipVault_1.6.0_x64-setup.exe`
