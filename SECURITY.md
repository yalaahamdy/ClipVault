## Reporting a Vulnerability

The ClipVault team takes the security and privacy of our users very seriously.

Because ClipVault operates **100% locally** on your machine with **zero network telemetry or outbound connections**, security vulnerabilities typically relate to:
- Local database file storage encryption or permissions
- Clipboard read/write safety in multi-user Windows environments
- Process isolation and WebView2 runtime boundaries

If you believe you have discovered a security vulnerability in ClipVault:

1. **Do not disclose the issue publicly.**
2. Email details to the maintainers or open a confidential security advisory via GitHub Security Advisories tab.
3. Provide a clear reproduction with steps, sample payload, and OS version details.

We commit to acknowledging your report within 48 hours and providing a target remediation timeline.
